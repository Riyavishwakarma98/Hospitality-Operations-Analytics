# Hospitality-Operations-Analytics
End-to-end Hospitality &amp; Revenue Analytics project using Excel, SQL, Tableau, and Power BI.

## Executive Summary
Shodwe Group, a nationwide hospitality chain, faced fragmented reporting and delayed operational decision-making due to legacy manual Excel workflows. This project delivers an end-to-end BI solution that centralizes property metrics, occupancy rates, and revenue streams across multi-city hotel chains.

## Project Scope & Workflow
1. **Excel Data Preparation:** Conducted baseline cleaning, initial KPI definitions, and reporting requirements validation.
2. **SQL Schema Setup:** Loaded structured records into MySQL, normalized relational tables, and defined primary/foreign key joins.
3. **BI Dashboard Development:** Connected SQL models into Tableau and Power BI to build interactive visuals with drill-through filters.
4. **Quality Assurance (QA):** Reconciled database query outputs directly against dashboard metrics to ensure total data integrity.

## Core KPIs Tracked
- **Occupancy & Capacity:** Occupancy Rate (%), Total Bookings, Utilized Room Capacity.
- **Financial Performance:** Total Revenue, RevPAR, Weekday vs. Weekend Revenue Splits.
- **Operational Risk:** Cancellation Patterns, Booking Lead Times, No-Show Rates.
- **Demographics:** Revenue breakdown by Hotel State, Location, and Room Category (Standard, Deluxe, Suite).

## Tools Used
- **Excel:** Baseline cleaning & KPI definitions
- **MySQL:** Relational schema design & normalization
- **Power BI & Tableau:** Dynamic interactive dashboards
- **PowerPoint:** Executive review reporting
